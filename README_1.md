# Şekil Ordusu

Telefonda oynanan, şekillerden ordu kurup savaştırdığın bir strateji oyunu.

- Askerlerini parmağınla sahaya boya, **SAVAŞ**'a bas.
- 11 birim tipi, dallanan yetenek ağacı, karşı tip sistemi
- Kampanya, Taktik, Sonsuz, Günlük Meydan Okuma, Haftalık Turnuva ve Sandbox modları
- 3 farklı patron, hava durumu (yağmur/sis/gece), komutan yetenekleri
- Seviye editörü + kodla paylaşma, rekorlar, kolay mod, ordu desenleri
- 2D / 3D / FLY kamera, savaş tekrarı, başarımlar, temalar
- 20 dil: Türkçe, English, Deutsch, Español, Français, Italiano, Português, Русский, Українська, Polski, Nederlands, العربية, 日本語, 한국어, 中文, हिन्दी, Bahasa Indonesia, Tiếng Việt, Azərbaycanca, Română

## Oyna

`index.html` tek başına çalışır. `manifest.json`, `sw.js` ve ikonlar da yüklenirse oyun telefona **uygulama gibi kurulur** ve internetsiz açılır (Chrome: ⋮ › Ana ekrana ekle, iPhone Safari: Paylaş › Ana Ekrana Ekle). GitHub Pages açıksa:
